# Smart City Crime Prediction System

An AI-powered crime prediction system that automatically categorizes citizen complaints using Machine Learning (Naive Bayes Algorithm with Pipeline).

## 🌟 Features

- **AI-Powered Classification**: Automatically categorizes complaints using Naive Bayes
- **Location-Based Routing**: Complaints routed to zone-specific administrators
- **Real-Time Analytics**: Monthly crime statistics and trends with bar graphs
- **Citizen Dashboard**: Submit and track complaints
- **Admin Dashboard**: Manage complaints and view analytics
- **Responsive Design**: Works on all devices

## 🚀 Tech Stack

- **Backend**: FastAPI (Python)
- **Frontend**: HTML, CSS, JavaScript
- **Database**: SQLite
- **ML Algorithm**: Naive Bayes with Pipeline
- **Charts**: Chart.js

## 📋 Prerequisites

- Python 3.10+
- pip (Python package manager)
